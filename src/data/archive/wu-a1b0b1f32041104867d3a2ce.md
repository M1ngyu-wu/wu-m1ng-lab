### 第16题：函数重载

题目：

已知函数 f 的原型声明为：

```
int f(int, int, int);
```

下列重载函数的原型声明中不正确的是？

A. `char f(int, int);`

B. `double f(int, int, double);`

C. `double f(int, int, int);`

D. `int f(int, char*);`

正确答案：C

首先理解函数重载：

函数名相同，但是参数列表不同，可以构成函数重载。

例如：

```
int add(int a, int b)
{
    return a + b;
}

double add(double a, double b)
{
    return a + b;
}
```

虽然函数名相同，但参数类型不同，因此可以同时存在。

逐个分析：

| 选项 | 参数列表             | 是否可以重载         |
| ---- | -------------------- | -------------------- |
| A    | `(int, int)`         | 可以，参数数量不同   |
| B    | `(int, int, double)` | 可以，参数类型不同   |
| C    | `(int, int, int)`    | 不可以，参数完全相同 |
| D    | `(int, char*)`       | 可以，参数类型不同   |

为什么 C 不可以？

原函数：

```
int f(int, int, int);
```

C 选项：

```
double f(int, int, int);
```

它们只有返回值类型不同。

C++ 不允许仅仅通过返回值类型不同来构成函数重载。
